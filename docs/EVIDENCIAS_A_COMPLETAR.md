# Evidencias pendientes de la Actividad 5

Este repositorio incluye el código, el script SQL y los diagramas. Para cumplir la rúbrica debes ejecutar el programa en tu computadora y capturar:

1. Creación de un producto (formulario, lista y consulta SQL).
2. Lectura de productos (Index en el navegador).
3. Edición de precio o stock (antes / después).
4. Eliminación de un producto (antes / después).
5. Error de validación (precio 0 o SKU duplicado).
6. Git: `git status`, `git log --oneline` y URL del repositorio público.

No se incluyen imágenes fabricadas o resultados de pruebas no realizadas.
